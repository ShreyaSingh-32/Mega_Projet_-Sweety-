# Sweety - Python Voice Assistant

Sweety is a Python-based voice assistant inspired by Google Assistant and JARVIS. It listens to voice commands, understands the user's request, and performs different actions such as opening applications and websites, searching Google, and playing songs on YouTube.

## 🚀 Features

- 🎙️ Voice-based interaction using Speech Recognition
- 🗣️ Converts spoken commands into actionable tasks
- 🌐 Opens Google and other websites through voice commands
- ▶️ Searches and plays songs on YouTube using voice commands
- 📱 Can open applications such as WhatsApp
- 🔗 API integration for interactive functionality
- ⚙️ Automation of common desktop/web tasks
- 🐍 Built using Python and multiple Python libraries
- 🛠️ Developed and tested inside a Python virtual environment
- 🐞 Debugging and error-solving during development

## 🧠 How It Works

1. The assistant listens to the user's voice command.
2. Speech Recognition converts the spoken input into text.
3. The program processes the command and identifies the requested action.
4. Based on the command, Sweety performs the corresponding task.
5. For example:
   - "Open Google" → Opens Google
   - "Open WhatsApp" → Opens WhatsApp
   - "Open YouTube and play [song]" → Searches for and plays the requested song

The virtual environment itself is not included in the repository. Project dependencies can be maintained in a `requirements.txt` file.
